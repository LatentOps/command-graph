# Ordin v0.2.0

Ordin 0.2.0 adds maintained agent integrations, structured action review, and
local evidence for decisions and execution results. The release includes a
Python library, the `ordin` CLI, `ordin-claude-hook`, and `ordin-mcp-proxy`.

## Changes since v0.1.0

- Embed reviews through `Ordin` and `AgentGate`, or adapt generic tool and MCP
  calls while preserving their exact identities and arguments.
- Connect Claude Code hooks to Ordin's permission decisions and post-tool
  observations. Run the stdio MCP proxy in front of a configured server to review
  tool calls before forwarding them.
- Apply explicit local action policies and bounded temporal policies. Reviews
  expose structured resources, provenance, capability recommendations, and
  optional redacted audit evidence.
- Use expanded infrastructure semantics for cloud, Kubernetes, Terraform,
  database, remote, service, and repository operations.
- Replay promoted failures and evaluate local integration behavior with versioned
  fixtures, conformance checks, diagnostics, and recorded reports.
- Follow the rewritten README and runnable integration examples. The stdin
  review example now satisfies its published schema.

The release also fixes tool-identity normalization, proxy shutdown when the
upstream server exits, and ambiguous MCP JSON handling. The proxy rejects
duplicate members, non-finite numbers, and excessive nesting before forwarding.

## Install

```bash
python -m pip install "git+https://github.com/LatentOps/ordin.git@v0.2.0"
ordin doctor
```

The GitHub Release provides `ordin-0.2.0-py3-none-any.whl` and
`ordin-0.2.0.tar.gz`. Core search and review require no runtime dependencies beyond
Python. CI validates Python 3.10–3.13 and installed CLI behavior on Linux.

Review APIs return decisions without executing actions. Execution permissions,
sandboxing, and approval UI remain the integrating runtime's responsibility.
The published evaluation reports describe finite local workloads and their
recorded environment; they do not establish universal agent safety.
